Το ζητούμενο μας ήταν να γράψουμε 5 διαφορετικές συναρτήσεις σε γλώσσα Golang που να τυπώνουν ένα ορθογώνιο με πλάτος x και ύψος y. Σε κάθε μία περίπτωση το ορθογώνιο θα εμφανίζεται με συγκεκριμένους χαρακτήρες. 

QuadA: Οι γωνίες συμβολίζονται με "ο", η πάνω και η κάτω πλευρά με "-", η δεξιά και η αριστερά πλευρά με "|" και το εσωτερικό με " ".
QuadB: Η πάνω αριστερά και η κάτω δεξιά γωνίες συμβολίζονται με "/", η πάνω δεξιά και η κάτω αριστερά γωνίες με "\", οι πλευρές με "*" και το εσωτερικό " ".
QuadC: Η πάνω αριστερά και η πάνω δεξιά γωνίες συμβολίζονται με "Α", η κάτω δεξιά και η κάτω αριστερά γωνίες με "C", οι πλευρές με "Β" και το εσωτερικό " ".
QuadD: Η πάνω αριστερά και η κάτω αριστερά γωνίες συμβολίζονται με "Α", η πάνω δεξιά και η κάτω δεξιά γωνίες με "C", οι πλευρές με "Β" και το εσωτερικό " ".
QuadE: Η πάνω αριστερά και η κάτω δεξιά γωνίες συμβολίζονται με "Α", η πάνω δεξιά και η κάτω αριστερά γωνίες με "C", οι πλευρές με "Β" και το εσωτερικό " ".

Με την εκτύπωση κάθε ορθογωνίου εμφανίζεται μία καινούργια γραμμή (\n).

Τέλος, σε περίπτωση που κάποιο από τα x, y είναι αρνητικά, η εκάστοτε συνάρτηση δεν εκτυπώνει κάτι. 


Μέθοδος Επίλυσης/Ανάλυση Κώδικα (Με παράδειγμα το QuadA)

package piscine -> Δηλώνει το πακέτο που ανήκει ο κώδικας. Εδώ η ονομασία είναι "piscine". 

import "fmt" -> Εισάγει τις πληροφορίες από το πακέτο "fmt".

func QuadA(x, y int) { -> Ορίζει την συνάρτηση QuadA, με παραμέτρους x και y, όπου x αναφέρεται στο πλάτος και y στο ύψος.
	if x <= 0 || y <= 0 {
		return
	} -> Αν οι παράμετροι είναι μηδενικοί ή αρνητικοί, η συνάρτηση δεν εκτυπώνει αποτέλεσμα.

	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ { -> Δύο for loops που περνάνε από κάθε θέση του πλαισίου, δηλαδή γραμμές και στήλες.
			if (row == 1 && col == 1) || (row == 1 && col == x) ||
				(row == y && col == 1) || (row == y && col == x) {
				fmt.Print("o") -> Αν η θέση είναι γωνία, εκτυπώνει "ο".
			} else if row == 1 || row == y {
				fmt.Print("-") -> Αν είναι πάνω ή κάτω πλευρά, εκτυπώνει "-".
			} else if col == 1 || col == x {
				fmt.Print("|") -> Αν είναι αριστερά ή δεξιά πλευρά, εκτυπώνει "|".
			} else {
				fmt.Print(" ") -> Αν είναι στο εσωτερικό, εκτυπώνει " ".
			}
		}
		fmt.Println() -> Μετά από κάθε γραμμή, προχωράει στην επόμενη.
	}
}
